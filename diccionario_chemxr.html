ChemXR / Modelo de datos / revisión del equipo

Diccionario de datos · PostgreSQL

Plataforma de aprendizaje libre + campus institucional · Especificación orientativa de la estructura para Flyway. El modelo necesita validación funcional y pruebas de integración antes de producción.

Cómo leer este documento. Cada entidad contiene propósito, columnas, tipos, nulabilidad, valores predeterminados, claves externas, restricciones y relaciones. Usa el buscador para localizar palabras como matrícula, cuota, grupo, simulador o certificado. Los identificadores UUID no representan las rutas de la interfaz.

Decisiones y límites pendientes

  1. Este conjunto es un baseline para instalaciones nuevas; no debe ejecutarse directamente sobre una instancia ya migrada con Flyway.
  2. Separar pagos de ChemXR (platform) de cobros de centros educativos (finance).
  3. Una persona puede estar inscrita en cursos de distintas instituciones; el acceso multi-tenant debe verificarse en API, consultas y políticas RLS.
  4. Retención, privacidad de menores, cifrado, autorización de contenido y registros de auditoría deben revisarse antes de producción.
  5. Las reglas cruzadas (miembro de sección / misma institución, límites de planes, notas, cupos, colisiones de reserva y asignación financiera) requieren validación transaccional, y algunas merecerán constraints, triggers o procedimientos adicionales.
  6. La documentación no incluye registros históricos ni migración de datos desde la BD antigua. Para una base desplegada se precisa estrategia de backfill y pruebas.
  7. Las tablas se diseñaron para soportar capacidades previstas, no obligan a implementarlas todas desde el primer lanzamiento.

Fuente de requisitos: SQL original y capturas compartidas; referencia adicional de funciones educativas públicas de Udemy, Platzi y Netzun. No se incluyen imágenes ni información privada de plataformas externas.
